藥安 · 高齡用藥評估

雲端開啟入口，
處方留在自己的電腦。

圖片、Excel、藥品辨識與臨床篩檢都由本機服務處理。這個入口沒有病人輸入欄位，也不接收查詢內容或結果。

第一次使用

  1. 下載 Windows 64 位元套件，解壓縮至未同步到雲端的本機資料夾。
  2. 執行 ElderMedicationReview.exe，保持服務視窗開啟。首次啟動會建立公開藥品索引，需稍候。
  3. 瀏覽器將開啟整合工作台：匯入、核對、藥品不適切性分析表、儲存評估及日期區間統計匯出。先在「公開資料檢核」檢查文獻，勾選並確認下載後，確認臨床來源與規則狀態。
下載 Windows 套件

進入發行頁後，下載 Assets 中的 ElderMedicationReview-Windows-x64.zip；若尚未有發行版本，表示套件仍未建置完成。請依 SHA256SUMS.txt 核對檔案。

已安裝並啟動服務

請在安裝服務的同一台電腦操作。以下連結會開啟本機頁面，所有資料輸入與結果都在該頁面完成。

開啟完整評估與統計 UI ↗

無法連線時，請先執行套件中的程式。127.0.0.1 代表你自己的電腦，不能當成別人的服務網址。
